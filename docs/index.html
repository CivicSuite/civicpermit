CivicSuite / CivicPermit

Permit intake support that keeps staff responsible.

CivicPermit is the permit pre-application and development-review intake support module for CivicSuite.

v0.1.1 permit intake foundation + intake persistence

Current State

The package shell, API foundation, deterministic requirement lookup, optional database-backed requirement and intake records via CIVICPERMIT_INTAKE_DB_URL, intake-readiness review, submittal outline, records-ready export checklist, and public sample UI exist. Permit approvals, legal advice, live GIS, live LLM calls, permit application ingestion, permitting-system integrations, and production staff-review queues are not shipped yet.

Product Promise

  • Find permit requirement context with citations.
  • Surface sample intake-readiness factors for staff review.
  • Draft submittal outlines without making official completeness decisions.
  • Preserve inquiry/checklist/reviewer provenance for municipal records.
