# CivicPermit Implementation Plan

CivicPermit v0.2.0 ships the permit pre-application product lane: runtime shell, permit requirement lookup, staff-gated intake persistence, staff review queue workflows, review-required development-review context packets for CivicZone/CivicCode references, adversarial local integration mocks, intake-readiness review, submittal outline, records-ready export checklist, public sample UI, and CivicCore v1 alignment.

Future work stays outside this release: official permit approvals, completeness determinations, fee calculation, inspection scheduling, live GIS, live LLM calls, and permitting-system writeback.
